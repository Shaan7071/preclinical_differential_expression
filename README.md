# Preclinical RNA-Seq Pipeline & Dataset Registry

This repository contains a modular bioinformatics pipeline for processing preclinical RNA-seq data and obtaining differential expression results. The workflow standardizes 
raw counts, performs quality control, executes differential expression analysis 
(DEA), and maps results to human orthologs for pathway enrichment.

---
## ⚙️ Installation

To ensure all bioinformatics dependencies (like `pydeseq2`, `gseapy`, and `gprofiler-official`) are correctly installed, run the following in your terminal:

```bash
pip install -r requirements.txt
```
---

## 📂 Directory Structure

Each project folder (e.g., `Mouse-2023/`) is automatically generated and organized to maintain data integrity:

* **`documentation/`**: Protocols, methodology documents, and associated publications.
* **`raw-data/`**: Original count matrices and metadata files.
* **`processed-data/`**: Formatted inputs for `pydeseq2` and quality metrics (`qc_metrics.csv`).
* **`QC-results/`**: Diagnostic plots, including PCA, correlation heatmaps, and normality checks.
* **`DEA-results/`**: Gene-level statistical outputs from `pydeseq2`, including both model-specific and human ortholog mappings.
* **`GSEA-results/`**: Cleaned pathway-level results (e.g., GO, KEGG, Reactome) and ranked gene lists.
* **`raw-GSEA-results/`**: Direct outputs generated by `gseapy`.

---

## 🛠️ How These Files Work

The analysis follows a sequential notebook-based execution:

1.  **Setup (`0-setup.ipynb`)**: Initializes the standard subfolder architecture for a new dataset.
2.  **Input Standardization (`1-make-*-inputs.ipynb`)**: Unique for each dataset. Converts raw data into a counts matrix of format `samples x genes` and a metadata file for the pipeline.
3.  **Quality Control (`2-sample-QC.ipynb`)**: Normalizes and log compresses counts, 
then generates sample clustering plots and QC metrics for manual outlier detection. 
4.  **Differential Expression (`3-run-deseq2.ipynb`)**: Uses a Generalized Linear Model (GLM) to identify significant genes.
5.  **Ortholog Enrichment (`4-ortholog-enrichment.ipynb`)**: Translates model gene IDs to human orthologs and runs a GSEA.

Note: There are heuristics taken in mapping to human orthologs due to a lack of one-to-one mapping, such that any results that come from human-mapped results should be reviewed by a biologist and verified at the level of the model organism.

#### Handling multiple human orthologs for a single model organism gene (one-to-many):

Assigning the same statistics to multiple human genes effectively multiples that gene's signal, inflating the enrichment score for that pathway. For example, a single zebrafish UGT gene maps to 19 human UGT genes. When running the GSEA, the relevant pathway will contain those 19 UGT genes and thus that one fish gene will be inflated. However, because the fish gene is capturing the functions of 19 human genes, it can be interpreted as a faithful representation. Choosing only 1/19 human genes would make that pathway non-significant, when it may be in the zebrafish. For this reason, all human genes were kept.

#### Handling a single human ortholog for multiple fish genes (many-to-one):

GSEA requires a unique rank and score for each gene in its input list, so duplicate human genes must be collapsed. Gene duplication in the zebrafish genome, mainly from the teleost-specific (TS) whole-genome duplication, results in multiple paralogs for a human gene, with the paralogs continuing to evolve and sub-functionalize. Usually, one paralog retains the ancestral role while the other(s) take on other niches (sub-functionalization) or a new role (neofunctionalization). In rare cases, a dosage selection can take place where an additive effect emerges. There are 3 ways to collapse a list of model organism genes into a single human ortholog:

- Keeping only the paralog with the most extreme signal. This is best for handling neo-functionalization where paralog function has diverged. However, this is a heuristic. The paralog with the highest absolute Wald statistic is not necessarily the one that has retained the ancestral function.
- Summing the counts of each paralog before DEA. This works for paralogs which act additively in a dosage relationship. For any other situation, this method fails.
- Taking the mean expression of all paralogs. This can work for paralogs which have undergone sub-functionalization, where they each take on niche roles that the single human ortholog does. However, in the case where paralogs are individually regulated, such as a case where neofunctionalization has occurred and one paralog is upregulated and another is downregulated, the mean no longer works. This only works if all paralogs are being regulated together.

Thus, choosing the most extreme paralog is the best guess at identifying the one acting as the functional representative of the gene family. This is the heuristic that must be investigated at the gene-level of the model organism.
